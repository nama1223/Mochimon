## 概要

「誰が・何を・いつ渡したか」を記録する、もちものリスト管理アプリ。身内向けのため非公開です（このページの起動ボタンは無効になっています）。

### しくみ
団体パスワードで入る共有スペースで、楽器や備品などの受け渡しを記録。あとから「あれ、誰に渡したっけ」をたどることができます。
各個人の「もちもの」の追加や削除は自由に出来ますが、受け渡しの記録は日時つきで保存され、消せない仕様となっています。
